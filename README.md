## Program Requirements:

- The application's first outputted line should be the application's name in the form of "<Your Student ID> Spreadsheet Automation Menu."

- The application should receive input and conclude by telling the user the selected option number and the current date and time. Remember, what differentiates similar applications is the conciseness and meaningful ways in which they present data to the user. To print the current date and time, use the following example:
  from datetime import datetime
  
  print("the time and date is",str(datetime.now()))

- In the Python code file, add a comment one line above where user input is being requested. Use the following comment "The next line retrieves the inputted option and stores into the variable called <variable>." Then, replace <variable> with the variable name you choose to use.
